Download Pastel

The newest release is {{ version }}. Pastel needs Free Pascal 3.2 or newer; pastel doctor checks the rest.

Linux

Free Pascal, then Pastel into ~/.pastel with pastel on your PATH:

sudo apt install fpc fpc-source
curl -fsSL {{ releases }}/download/install.sh | sh
pastel doctor

Desktop apps also use SDL2 and FreeType: sudo apt install libsdl2-2.0-0 libfreetype6. x86-64 and ARM64 (Raspberry Pi).

The .tar.gz from Releases

Windows

  1. Install Free Pascal from freepascal.org.
  2. Unpack pastel-{{ version }}-windows-x86_64.zip, for example to C:\Pastel.
  3. Add its bin folder to PATH, open a new terminal and run pastel doctor.

Windows programs get SDL2.dll and freetype.dll next to them by themselves.

VS Code extension

The Welcome page and New Project wizard, the form designer, completion, debugging, tests and the live preview.

Search for Pastel in the Extensions view, or install the .vsix of the release:

code --install-extension pastel-vscode-*.vsix

Build it from the sources

git clone {{ github }}.git pastel
cd pastel
./build.sh            # Windows: build.bat
ln -s "$PWD/bin/pastel" ~/.local/bin/pastel

Building for other platforms

  • Windows programs on Linux: pastel doctor --install windows (needs fpc-source).
  • Android: pastel doctor --install android, then pastel run --target android; see Android.
  • Raspberry Pi: a cross-compiler, most easily with fpcupdeluxe.
