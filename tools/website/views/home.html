Object Pascal apps for the desktop, the phone and the web.

Pastel is a framework and a toolchain on top of Free Pascal: one command-line tool, a form designer in VS Code, and libraries for windows, phones, web sites, APIs, services and console programs. Write it once, build it for Linux, Windows, Raspberry Pi and Android.

Get started Download

Desktop apps

Forms in .pform files, designed in VS Code the way Delphi does it: palette, Structure, Object Inspector, free placement. About 40 controls, data binding, menus, themes, hot reload.

Forms · Controls

Android preview

The same forms on a phone: pastel run --target android builds an APK without Android Studio and starts it on the phone.

Android

Web sites and APIs

A web server, REST APIs with JWT, SQLite, PostgreSQL and MySQL with migrations, and pages from Blade-like templates with Bootstrap. This site is made that way.

Web pages · Web APIs

Console programs and services

Arguments and --help, colors, tables, files, HTTP, JSON, settings, logging, background jobs, a systemd unit, .deb and Docker packages.

Console · Services

A modern editor

The VS Code extension: a New Project wizard, completion, hover, rename, compiler errors while typing, debugging, the designer and a live preview.

VS Code extension

One project, many platforms

Every project has the same shape and a pastel.toml. pastel build --all builds every platform; pastel package makes installers, AppImages and archives.

Projects · Commands

From nothing to a running app

Install Free Pascal and Pastel, then make a project. pastel doctor says what this computer can build and installs what is missing.

Getting started, in fifteen minutes 
pastel new app hello      # a desktop app with a form
cd hello
pastel run                # opens the window; edit the form while it runs
pastel build --target windows
pastel package            # an installer, an AppImage, a .deb
