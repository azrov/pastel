#The handbook: learning Object Pascal and Pastel

The Pastel Handbook teaches the Object Pascal language from the first line to an intermediate level, and Pastel's apps with it, in 22 chapters and one program that grows through all of them — Pocket, a money tracker, from a few lines in a terminal to an app with a database, charts, reports, two languages and an Android package. No earlier Pascal needed; every program in it is compiled and checked with every change.

#For contributors

Every new feature comes with its documentation and an example in the same change — a page or a section here, a .pform and code example for controls, an entry for commands. The tests check that every control is in the controls reference and every command in the command reference. See CONTRIBUTING.md.
