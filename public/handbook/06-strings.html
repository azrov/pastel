#6. Text

Most programs spend much of their time with text: names, notes, file lines, messages. This chapter shows how Pascal keeps text, the routines that cut and search it, and the one thing that surprises everyone — letters like ş, é or €.

#Strings are UTF-8 bytes

A string (with {$H+}) holds text of any length. Pastel programs keep it in UTF-8, the encoding of the web and of Linux: English letters take one byte each, letters like ş or ü two, € three, an emoji four.

Length counts bytes, and S[I] is the I-th byte:

program Bytes;

{$mode objfpc}{$H+}

uses
  SysUtils, Pastel.Text;

var
  Name: string;
begin
  Name := 'Ayşe';
  WriteLn('Length:    ', Length(Name));
  WriteLn('CharCount: ', CharCount(Name));
  WriteLn('First byte: ', Name[1]);
  WriteLn('Upper:     ', Upper(Name));
  WriteLn('UpperCase: ', UpperCase(Name));
  WriteLn('Turkish:   ', Upper('istanbul', 'tr'));
end.

Length:    5
CharCount: 4
First byte: A
Upper:     AYŞE
UpperCase: AYşE
Turkish:   İSTANBUL
  • Length says 5 for Ayşe: the ş is two bytes. CharCount (from Pastel.Text) counts the letters a person sees.
  • UpperCase from SysUtils only knows the English letters a–z, so it leaves ş alone. Upper and Lower from Pastel.Text know every alphabet — and with 'tr' they follow Turkish, where i becomes İ.

The rule of thumb: the routines below work on bytes, and that is fine for searching, cutting at a found position, splitting and joining — UTF-8 is built so that these never cut a letter in half by accident. Count letters with CharCount, cut by letters with CharCopy, and change case with Upper/Lower.

#The everyday routines

program Everyday;

{$mode objfpc}{$H+}

uses
  SysUtils;

var
  S: string;
begin
  S := '  Coffee with milk  ';
  WriteLn('[', Trim(S), ']');
  S := Trim(S);
  WriteLn('Pos of "with": ', Pos('with', S));
  WriteLn('Copy(S, 8, 4): ', Copy(S, 8, 4));
  WriteLn('Replaced: ', StringReplace(S, 'milk', 'sugar', []));
  WriteLn('Lower: ', LowerCase(S));
  WriteLn('Same text? ', SameText('COFFEE', 'coffee'));
  Delete(S, 1, 7);                 // remove 7 bytes from position 1
  WriteLn('After Delete: ', S);
  Insert('tea ', S, 1);
  WriteLn('After Insert: ', S);
  WriteLn('Quoted: ', QuotedStr('It''s'));
end.

[Coffee with milk]
Pos of "with": 8
Copy(S, 8, 4): with
Replaced: Coffee with sugar
Lower: coffee with milk
Same text? TRUE
After Delete: with milk
After Insert: tea with milk
Quoted: 'It''s'
Pos(Sub, S) where Sub starts in S (from 1); 0 when it is not there
Copy(S, From, Count) Count bytes from position From (MaxInt for "the rest")
Delete(S, From, Count), Insert(Sub, S, At) change S itself
Trim, TrimLeft, TrimRight without spaces (and tabs, line breaks) at the ends
StringReplace(S, Old, New, Flags) [rfReplaceAll] for every one, [rfIgnoreCase] for any case
SameText(A, B), CompareText(A, B) compare without case (English letters)
LowerCase, UpperCase English letters only — Lower, Upper for every language

#String helpers: Split, Join and friends

Strings also have methods, written after a dot:

program Helpers;

{$mode objfpc}{$H+}

uses
  SysUtils;

var
  Line: string;
  Parts: TStringArray;
  P: string;
begin
  Line := '2026-11-03;Food;12.50;Lunch';
  Parts := Line.Split([';']);
  WriteLn('Fields: ', Length(Parts));
  for P in Parts do
    WriteLn('  ', P);
  WriteLn(string.Join(' | ', Parts));
  WriteLn('Starts with 2026? ', Line.StartsWith('2026'));
  WriteLn('Has Food? ', Line.Contains('Food'));
  WriteLn('Index of ;: ', Line.IndexOf(';'));
end.

Fields: 4
  2026-11-03
  Food
  12.50
  Lunch
2026-11-03 | Food | 12.50 | Lunch
Starts with 2026? TRUE
Has Food? TRUE
Index of ;: 10

Careful: the helpers count from 0 (IndexOf says 10 where Pos would say 11), the classic routines from 1. Split gives a TStringArray — a dynamic array of strings.

#Building text

Joining strings with + in a loop is simple and fine for most uses:

program Building;

{$mode objfpc}{$H+}

uses
  SysUtils;

var
  I: Integer;
  S: string;
begin
  S := '';
  for I := 1 to 5 do
  begin
    if S <> '' then
      S := S + ', ';
    S := S + IntToStr(I * I);
  end;
  WriteLn('Squares: ', S);
  WriteLn(StringOfChar('=', 20));
  WriteLn(Format('%-10s|%10s|', ['left', 'right']));
end.

Squares: 1, 4, 9, 16, 25
====================
left      |     right|

For long texts built from thousands of pieces, a TStringList (chapter 10) or TStringBuilder is faster.

#In Pocket: reading an amount

People type amounts in different ways: 12, 12.5, 12,50, 1,234.50, or — in many countries — 1.234,50. Pocket accepts all of them. The rule: the last dot or comma with one or two digits after it starts the cents; other dots and commas only group thousands.

program ParseMoney;

{$mode objfpc}{$H+}

uses
  SysUtils;

function TryParseMoney(const Text: string; out Amount: Currency): Boolean;
var
  S, Clean: string;
  I, DecimalAt: Integer;
  Negative: Boolean;
  FS: TFormatSettings;
begin
  Amount := 0;
  S := Trim(Text);
  Negative := (S <> '') and (S[1] = '-');
  if Negative then
    Delete(S, 1, 1);
  if S = '' then
    Exit(False);
  { where the cents start: the last separator with one or two digits after it }
  DecimalAt := 0;
  for I := Length(S) downto 1 do
    if S[I] in ['.', ','] then
    begin
      if Length(S) - I <= 2 then
        DecimalAt := I;
      Break;
    end;
  Clean := '';
  for I := 1 to Length(S) do
    if S[I] in ['0'..'9'] then
      Clean := Clean + S[I]
    else if I = DecimalAt then
      Clean := Clean + '.'
    else if not (S[I] in ['.', ',', ' ']) then
      Exit(False);            { a letter or another sign: not an amount }
  if (Clean = '') or (Clean = '.') then
    Exit(False);
  { a dot, whatever the computer's language writes }
  FS := DefaultFormatSettings;
  FS.DecimalSeparator := '.';
  Result := TryStrToCurr(Clean, Amount, FS);
  if Result and Negative then
    Amount := -Amount;
end;

procedure Try_(const S: string);
var
  A: Currency;
begin
  if TryParseMoney(S, A) then
    WriteLn(Format('%-12s -> %s', ['"' + S + '"', CurrToStr(A)]))
  else
    WriteLn(Format('%-12s -> not an amount', ['"' + S + '"']));
end;

begin
  Try_('12');
  Try_('12.5');
  Try_(' 12,50 ');
  Try_('1,234.50');
  Try_('1.234,50');
  Try_('1,234');
  Try_('-7');
  Try_('12 EUR');
  Try_('');
end.

"12"         -> 12
"12.5"       -> 12.5
" 12,50 "    -> 12.5
"1,234.50"   -> 1234.5
"1.234,50"   -> 1234.5
"1,234"      -> 1234
"-7"         -> -7
"12 EUR"     -> not an amount
""           -> not an amount

Read it slowly — it uses nearly everything of this chapter and the ones before:

  • S[I] in ['.', ','] is a set test on one byte; digits, dots and commas are all one byte in UTF-8, so walking byte by byte is safe here: any other letter is simply "not a digit".
  • DefaultFormatSettings holds the computer's way of writing numbers. A copy with a dot as the decimal separator makes TryStrToCurr read 12.5 the same on every computer.
  • Each early Exit(False) handles one wrong case; the rest of the function only deals with good input.

#Exercises

  1. Count the words in a sentence (Split on spaces; skip empty parts).
  2. Write function Initials(const FullName: string): string — 'Ada King Lovelace' gives 'AKL'.
  3. Reverse a word. Try it with Ayşe. What goes wrong when you reverse bytes, and how would CharCopy help?
  4. ★ Write function IsValidEmail(const S: string): Boolean: one @, something before it, and a dot somewhere after it. (It will not catch everything — no simple test does.)
