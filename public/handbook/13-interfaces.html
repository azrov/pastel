#13. Interfaces and the command line

Pocket keeps its entries in a JSON file. In part 2 the app will keep them in a database. The code that uses the entries should not care where they live — and with an interface, it does not. At the end of this chapter, part 1 is done: Pocket is a finished command-line program.

#An interface is a promise

An interface lists methods, without code. A class that implements it promises to have them:

program Speakers;

{$mode objfpc}{$H+}

type
  ISpeaker = interface
    ['{4E0C5A7B-1D2E-4F3A-9B8C-7D6E5F4A3B2C}']
    function Speak: string;
  end;

  TDog = class(TInterfacedObject, ISpeaker)
    function Speak: string;
  end;

  TRobot = class(TInterfacedObject, ISpeaker)
    function Speak: string;
  end;

function TDog.Speak: string;
begin
  Result := 'Woof';
end;

function TRobot.Speak: string;
begin
  Result := 'Beep';
end;

procedure Introduce(S: ISpeaker);
begin
  WriteLn('It says: ', S.Speak);
end;

var
  S: ISpeaker;
begin
  S := TDog.Create;
  Introduce(S);
  S := TRobot.Create;            // the dog is freed here: nothing uses it any more
  Introduce(S);
end.                             // and the robot here

It says: Woof
It says: Beep
  • ISpeaker = interface lists what a speaker can do. By custom, interface names start with I. The GUID in brackets (any unique one: uuidgen in a terminal makes one) lets the program ask an object at run time whether it has the interface (Supports, as).
  • TDog = class(TInterfacedObject, ISpeaker) — a class, built on TInterfacedObject, that implements ISpeaker.
  • Introduce takes any speaker. It does not know dogs or robots, and never will need to.

How is that different from a parent class with a virtual method (chapter 8)? A class has only one parent, but it can implement many interfaces — a TDog could also be an IPet and an ISerializable. Interfaces describe what an object can do, not what it is.

#No Free: reference counting

There is no Free in that program, and no leak. An object used through an interface counts how many interface variables point to it; when the count drops to zero, it frees itself. S := TRobot.Create dropped the dog's count to zero.

The rule that comes with it: use such an object only through interface variables. Mixing a class variable and an interface variable for the same object leads to an object freed too early, or freed twice. Pocket's store follows the rule — the program holds an IEntryStore, never a TJsonStore.

#Pocket's store

The store is an interface with three methods, and its first implementation keeps the entries in the JSON file of chapter 11 — the procedures of that chapter, moved into a class. src/pocketstore.pas in pocket-core:

{ Where the entries are kept. The program only knows IEntryStore, so the
  place can change - a JSON file now, a database later - without changing
  the code that uses it.

    Store := TJsonStore.Create('pocket.json');     // Store: IEntryStore
    Store.Load(Entries);
    ...
    Store.Save(Entries);

  An interface variable frees its object by itself when nothing uses it any
  more: no Free for Store.

  Handbook: chapter 11 (files and JSON), chapter 13 (interfaces). }
unit PocketStore;

{$mode objfpc}{$H+}

interface

uses
  SysUtils, PocketEntries;

type
  EStoreError = class(Exception);

  IEntryStore = interface
    ['{6D1A4C1E-3F0B-4B5E-9C61-2A9E4F7B8D10}']
    { Fills Entries (emptied first) with what is kept. }
    procedure Load(Entries: TEntryList);
    { Keeps all of them; entries without an id get one. }
    procedure Save(Entries: TEntryList);
    { Where they are, for messages: a file's name. }
    function Where: string;
  end;

  (* The entries in a JSON file:
      [{"id": 1, "date": "2026-11-03", "kind": "expense",
        "category": "Food", "amount": 12.5, "note": "Lunch"}, ...] *)
  TJsonStore = class(TInterfacedObject, IEntryStore)
  private
    FFileName: string;
  public
    constructor Create(const AFileName: string);
    procedure Load(Entries: TEntryList);
    procedure Save(Entries: TEntryList);
    function Where: string;
  end;

{ '2026-11-03' and back; the files and the database keep dates this way. }
function DateToIso(D: TDateTime): string;
function IsoToDate(const S: string): TDateTime;

{ The next free id: one more than the biggest in the list. }
function NextId(Entries: TEntryList): Int64;

implementation

uses
  fpjson, Pastel.Json, Pastel.Files;

function DateToIso(D: TDateTime): string;
begin
  Result := FormatDateTime('yyyy"-"mm"-"dd', D);
end;

function IsoToDate(const S: string): TDateTime;
var
  Y, M, D: Integer;
begin
  if (Length(S) < 10) or not TryStrToInt(Copy(S, 1, 4), Y) or not TryStrToInt(Copy(S, 6, 2), M) or
    not TryStrToInt(Copy(S, 9, 2), D) or not TryEncodeDate(Y, M, D, Result) then
    raise EStoreError.CreateFmt('"%s" is not a date like 2026-11-03', [S]);
end;

function NextId(Entries: TEntryList): Int64;
var
  E: TEntry;
begin
  Result := 1;
  for E in Entries do
    if E.Id >= Result then
      Result := E.Id + 1;
end;

constructor TJsonStore.Create(const AFileName: string);
begin
  inherited Create;
  FFileName := AFileName;
end;

function TJsonStore.Where: string;
begin
  Result := FFileName;
end;

procedure TJsonStore.Load(Entries: TEntryList);
var
  Data: TJSONData;
  Item: TJSONData;
  Kind: TEntryKind;
  E: TEntry;
  I: Integer;
begin
  Entries.Clear;
  if not FileExists(FFileName) then
    Exit;                                  { nothing kept yet: an empty list }
  try
    Data := LoadJsonFile(FFileName);
  except
    on Ex: Exception do
      raise EStoreError.CreateFmt('%s cannot be read: %s', [FFileName, Ex.Message]);
  end;
  try
    if not (Data is TJSONArray) then
      raise EStoreError.CreateFmt('%s is not a list of entries', [FFileName]);
    for I := 0 to Data.Count - 1 do
    begin
      Item := Data.Items[I];
      if not TryParseKind(JStr(Item, 'kind'), Kind) then
        raise EStoreError.CreateFmt('%s: entry %d has the kind "%s"', [FFileName, I + 1, JStr(Item, 'kind')]);
      E := Entries.AddEntry(IsoToDate(JStr(Item, 'date')), Kind, JStr(Item, 'category'),
        JFloat(Item, 'amount'), JStr(Item, 'note'));
      E.Id := JInt(Item, 'id');
    end;
  finally
    Data.Free;
  end;
end;

procedure TJsonStore.Save(Entries: TEntryList);
var
  List: TJSONArray;
  E: TEntry;
begin
  List := TJSONArray.Create;
  try
    for E in Entries do
    begin
      if E.Id = 0 then
        E.Id := NextId(Entries);
      List.Add(JObject(['id', E.Id, 'date', DateToIso(E.Date), 'kind', KindName(E.Kind),
        'category', E.Category, 'amount', Double(E.Amount), 'note', E.Note]));
    end;
    if ExtractFileDir(FFileName) <> '' then
      EnsureDir(ExtractFileDir(FFileName));
    SaveJsonFile(FFileName, List);
  finally
    List.Free;
  end;
end;

end.

New things in it:

  • EStoreError is the exception for everything that can go wrong with the kept data; a program catches it to show the user one clear line.
  • TJsonStore.Load wraps LoadJsonFile's exception in an EStoreError that names the file.
  • IsoToDate checks the date with TryEncodeDate instead of trusting the file.
  • Save gives entries without an id the next free one.
  • The comment around the file's example uses (* … *): the JSON in it has { }, which would end a { } comment early.

The app in part 2 adds a second store, TDbStore, with a database behind the same three methods.

#Pocket on the command line

Command-line programs take arguments: pocket add 12.50 Food --note Lunch. Pastel.Args reads them: you describe the commands, options and flags, and it parses the command line, checks it, and writes the help:

{ Pocket on the command line: write down what you spend and earn, see where
  the money goes.

    pocket add 12.50 Food --note Lunch
    pocket add 3000 Salary --income
    pocket list --month 2026-11
    pocket report
    pocket remove 7

  The entries are kept in ~/.pocket/pocket.json (--file or POCKET_FILE: another one).
  Handbook: part 1, chapters 1 to 13. }
program PocketCli;

{$mode objfpc}{$H+}

uses
  SysUtils, DateUtils, Pastel.Args, Pastel.Term, Pastel.Files, AppInfo,
  PocketMoney, PocketEntries, PocketReports, PocketStore;

var
  Args: TArgs;
  Store: IEntryStore;
  Entries: TEntryList;

{ 'today', '2026-11-03' or '' (today) }
function ParseDay(const S: string): TDateTime;
begin
  if (S = '') or SameText(S, 'today') then
    Result := Date
  else if SameText(S, 'yesterday') then
    Result := Date - 1
  else
    Result := IsoToDate(S);
end;

{ '2026-11' -> the year and month; '' -> this month }
procedure ParseMonth(const S: string; out Year, Month: Word);
var
  Y, M: Integer;
begin
  if S = '' then
  begin
    Year := YearOf(Date);
    Month := MonthOf(Date);
    Exit;
  end;
  if (Length(S) <> 7) or (S[5] <> '-') or not TryStrToInt(Copy(S, 1, 4), Y) or
    not TryStrToInt(Copy(S, 6, 2), M) or (M < 1) or (M > 12) then
    raise EArgsError.CreateFmt('"%s" is not a month like 2026-11', [S]);
  Year := Y;
  Month := M;
end;

procedure AddCommand;
var
  Amount: Currency;
  Kind: TEntryKind;
  E: TEntry;
begin
  if not TryParseMoney(Args.Get('amount'), Amount) or (Amount <= 0) then
    raise EArgsError.CreateFmt('"%s" is not an amount like 12.50', [Args.Get('amount')]);
  if Args.Has('income') then
    Kind := ekIncome
  else
    Kind := ekExpense;
  E := Entries.AddEntry(ParseDay(Args.Get('date')), Kind, Args.Get('category'), Amount, Args.Get('note'));
  Store.Save(Entries);
  WriteLn(Format('Added #%d: %s %s %s', [E.Id, KindName(Kind), FormatMoney(Amount), E.Category]));
end;

procedure ListCommand;
var
  Year, Month: Word;
  InMonth: TEntryList;
  E: TEntry;
  T: TTable;
begin
  ParseMonth(Args.Get('month'), Year, Month);
  Entries.SortByDate;
  InMonth := Entries.InMonth(Year, Month);
  try
    if InMonth.Count = 0 then
    begin
      WriteLn(Format('Nothing in %d-%.2d.', [Year, Month]));
      Exit;
    end;
    T := TTable.Create(['#', 'Date', 'Category', 'Amount', 'Note']);
    try
      T.SetAlign(3, alRight);
      for E in InMonth do
        T.AddRow([IntToStr(E.Id), DateToIso(E.Date), E.Category, FormatMoney(E.SignedAmount), E.Note]);
      T.Print;
    finally
      T.Free;
    end;
    WriteLn(Format('Balance of %d-%.2d: %s', [Year, Month, FormatMoney(InMonth.Balance)]));
  finally
    InMonth.Free;
  end;
end;

procedure ReportCommand;
var
  Year, Month: Word;
  S: TMonthSummary;
  InMonth: TEntryList;
  T: TCategoryTotal;
begin
  ParseMonth(Args.Get('month'), Year, Month);
  S := MonthSummary(Entries, Year, Month);
  WriteLn(Bold(Format('%d-%.2d', [Year, Month])));
  WriteLn(Format('  Income    %12s', [FormatMoney(S.Income)]));
  WriteLn(Format('  Expenses  %12s', [FormatMoney(S.Expenses)]));
  WriteLn(Format('  Balance   %12s', [FormatMoney(S.Balance)]));
  InMonth := Entries.InMonth(Year, Month);
  try
    if InMonth.Expenses = 0 then
      Exit;
    WriteLn;
    WriteLn(Bold('Where it went'));
    for T in TotalsByCategory(InMonth, ekExpense) do
      WriteLn(Format('  %-12s %12s  %3.0f%%', [T.Category, FormatMoney(T.Amount), T.Percent]));
  finally
    InMonth.Free;
  end;
end;

procedure RemoveCommand;
var
  E: TEntry;
begin
  E := Entries.FindById(Args.GetInt('id'));
  if E = nil then
    raise EArgsError.CreateFmt('there is no entry #%d (pocket list shows them)', [Args.GetInt('id')]);
  Entries.Remove(E);          { the list owns it: this frees it too }
  Store.Save(Entries);
  WriteLn(Format('Removed #%d.', [Args.GetInt('id')]));
end;

begin
  Args := TArgs.Create(AppName, 'Write down what you spend and earn; see where the money goes.');
  Entries := TEntryList.Create;
  try
    Args.Version := AppVersion;
    Args.Option('file', 'f', 'Where the entries are kept').Env('POCKET_FILE')
      .Default(JoinPath([HomeDir, '.pocket', 'pocket.json']));
    with Args.Command('add', 'Write down an expense (or with --income an income)') do
    begin
      Positional('amount', 'How much: 12.50');
      Positional('category', 'Food, Rent, Salary...');
      Flag('income', 'i', 'It is an income');
      Option('date', 'd', 'The day: 2026-11-03, today, yesterday', 'today');
      Option('note', 'n', 'A few words');
    end;
    with Args.Command('list', 'The entries of a month') do
      Option('month', 'm', 'Which month: 2026-11 (this month when not given)');
    with Args.Command('report', 'A month in short, and where the money went') do
      Option('month', 'm', 'Which month: 2026-11 (this month when not given)');
    with Args.Command('remove', 'Remove an entry') do
      Positional('id', 'Its number (pocket list shows it)').IsInteger;
    Args.Example('pocket add 12.50 Food --note Lunch');
    Args.Example('pocket add 3000 Salary --income');
    Args.Example('pocket report --month 2026-11');
    Args.Parse;

    Store := TJsonStore.Create(Args.Get('file'));
    try
      Store.Load(Entries);
      case Args.CommandName of
        'add': AddCommand;
        'list': ListCommand;
        'report': ReportCommand;
        'remove': RemoveCommand;
      else
        WriteLn(Args.HelpText);
      end;
    except
      on E: EArgsError do
      begin
        WriteLn(StdErr, 'error: ', E.Message);
        ExitCode := 2;
      end;
      on E: EStoreError do
      begin
        WriteLn(StdErr, 'error: ', E.Message);
        ExitCode := 1;
      end;
    end;
  finally
    Entries.Free;
    Args.Free;
  end;
end.

How it fits together:

  • The description: Args.Command('add', …) makes a sub-command with its own Positional arguments, Options (--date 2026-11-03 or -d …) and Flags (--income). .Env('POCKET_FILE') lets an environment variable give the option; .Default(...) is used when neither does. Args.Parse reads the real command line; for --help, --version or a mistake it prints what is needed and ends the program.
  • One routine per command, chosen with case Args.CommandName of. Each is short because the work is in the library.
  • Errors the user can fix — a wrong amount, a missing entry, a broken file — are exceptions (EArgsError, EStoreError) caught in one place at the bottom: one line on the error output and an exit code (0 is success; scripts check it). Anything else is a bug and stops the program with its message.
  • InMonth.Free in ListCommand and ReportCommand — the leak of chapter 10, fixed.
  • TTable from Pastel.Term lines up the columns, also with letters like ş.

The project file of pocket-cli names the library:

[project]
name = "pocket"
version = "1.0.0"
type = "console"

[build]
main = "src/main.pas"

[dependencies]
pocket-core = { path = "../pocket-core" }
