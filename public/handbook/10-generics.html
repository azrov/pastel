#10. Lists, dictionaries and generics

Arrays (chapter 5) hold a row of values, but growing them by hand gets tedious, and finding a value means a loop. This chapter brings the containers every program uses: lists that grow by themselves, lists that own their objects, and dictionaries that find a value by its key. They are generic: written once, for any type.

#TStringList

The oldest and handiest list holds strings. It is in the Classes unit:

program Strings;

{$mode objfpc}{$H+}

uses
  Classes, SysUtils;

var
  L: TStringList;
  I: Integer;
begin
  L := TStringList.Create;
  try
    L.Add('pear');
    L.Add('apple');
    L.Add('fig');
    L.Sort;
    for I := 0 to L.Count - 1 do
      WriteLn(I, ': ', L[I]);
    WriteLn('apple is at ', L.IndexOf('apple'), ', kiwi at ', L.IndexOf('kiwi'));
    WriteLn('As one line: ', L.CommaText);

    L.Clear;
    L.Values['currency'] := 'EUR';      // name=value pairs
    L.Values['budget'] := '1500';
    WriteLn('Budget: ', L.Values['budget']);
    WriteLn(L.Text.Trim);
  finally
    L.Free;
  end;
end.

0: apple
1: fig
2: pear
apple is at 0, kiwi at -1
As one line: apple,fig,pear
Budget: 1500
currency=EUR
budget=1500

It also reads and writes text files a line each (LoadFromFile, SaveToFile), can keep itself sorted (Sorted := True) and refuse doubles (Duplicates := dupIgnore).

#Generic lists

The unit Generics.Collections has containers for any type. You choose the type of the elements when you use one — specialize TList<Integer> is a list of integers:

program Numbers;

{$mode objfpc}{$H+}

uses
  Generics.Collections;

type
  TIntList = specialize TList<Integer>;

var
  L: TIntList;
  N, Sum: Integer;
begin
  L := TIntList.Create;
  try
    L.Add(30);
    L.Add(10);
    L.AddRange([50, 20]);
    L.Sort;
    Sum := 0;
    for N in L do
    begin
      Write(N, ' ');
      Inc(Sum, N);
    end;
    WriteLn;
    WriteLn('Count: ', L.Count, ', sum: ', Sum, ', first: ', L.First, ', has 20: ', L.Contains(20));
    L.Delete(0);
    L.Remove(50);
    WriteLn('Left: ', L[0], ' ', L[1]);
  finally
    L.Free;
  end;
end.

10 20 30 50
Count: 4, sum: 110, first: 10, has 20: TRUE
Left: 20 30

specialize is the word {$mode objfpc} uses to make a type from a generic one; the type section gives it a name. (In {$mode delphi} you write TList<Integer> without it — see appendix B.)
Add, AddRange, Insert(I, X) put elements in
Delete(I), Remove(X), Clear take them out
L[I], Count, First, Last read them (from 0)
IndexOf(X), Contains(X) find one
Sort, Reverse order them
ToArray a dynamic array of them

#Lists of objects

A TObjectList holds objects and, unless told otherwise, owns them: removing an object from the list, or freeing the list, frees the object too. No loop of Frees, no leaks:

program Owned;

{$mode objfpc}{$H+}

uses
  Generics.Collections;

type
  TItem = class
    Name: string;
    constructor Create(const AName: string);
    destructor Destroy; override;
  end;

  TItemList = specialize TObjectList<TItem>;

constructor TItem.Create(const AName: string);
begin
  inherited Create;
  Name := AName;
end;

destructor TItem.Destroy;
begin
  WriteLn('  (', Name, ' freed)');
  inherited Destroy;
end;

var
  Items: TItemList;
  Item: TItem;
begin
  Items := TItemList.Create;               // OwnsObjects: True
  try
    Items.Add(TItem.Create('one'));
    Items.Add(TItem.Create('two'));
    Items.Add(TItem.Create('three'));
    for Item in Items do
      WriteLn(Item.Name);
    WriteLn('Removing two:');
    Items.Delete(1);
    WriteLn('Freeing the list:');
  finally
    Items.Free;
  end;
end.

one
two
three
Removing two:
  (two freed)
Freeing the list:
  (one freed)
  (three freed)

TItemList.Create(False) makes a list that does not own its objects: right when it only points to objects that belong to another list — a filtered view, say. Then it must not free them, and the owner must outlive it.

#Dictionaries

A TDictionary finds a value by its key at once, however many there are:

program PriceList;

{$mode objfpc}{$H+}
{$WARN 4046 OFF}

uses
  SysUtils, Generics.Collections;

type
  TPrices = specialize TDictionary<string, Currency>;

var
  Prices: TPrices;
  P: Currency;
begin
  Prices := TPrices.Create;
  try
    Prices.Add('tea', 2.50);
    Prices.Add('coffee', 3);
    Prices.AddOrSetValue('coffee', 3.20);     // replaces
    if Prices.TryGetValue('tea', P) then
      WriteLn('tea costs ', CurrToStr(P));
    if not Prices.ContainsKey('cake') then
      WriteLn('no cake');
    WriteLn(Prices.Count, ' prices; coffee: ', CurrToStr(Prices['coffee']));
  finally
    Prices.Free;
  end;
end.

tea costs 2.5
no cake
2 prices; coffee: 3.2
  • Add refuses a key that is already there (an exception); AddOrSetValue replaces.
  • Prices['cake'] raises when the key is missing; TryGetValue answers False instead.
  • A dictionary has no order. To list it sorted, copy its pairs (ToArray) or keys into a list and sort that.

{$WARN 4046 OFF}: Free Pascal 3.2 warns about its own code when a TDictionary is made ("Constructing a class … with abstract method"). The warning is harmless; this line switches it off for the unit.

#Sorting your way

Sort orders numbers and strings by themselves. For anything else, give it a function that compares two elements — negative when the first goes first, positive when the second does, 0 when equal:

program SortPeople;

{$mode objfpc}{$H+}

uses
  SysUtils, Generics.Collections, Generics.Defaults;

type
  TPerson = record
    Name: string;
    Age: Integer;
  end;
  TPeople = specialize TList<TPerson>;

function Person(const AName: string; AAge: Integer): TPerson;
begin
  Result.Name := AName;
  Result.Age := AAge;
end;

function ByAge(constref A, B: TPerson): Integer;
begin
  Result := A.Age - B.Age;
  if Result = 0 then
    Result := CompareStr(A.Name, B.Name);
end;

var
  People: TPeople;
  P: TPerson;
begin
  People := TPeople.Create;
  try
    People.AddRange([Person('Mia', 34), Person('Ali', 27), Person('Ada', 34)]);
    People.Sort(specialize TComparer<TPerson>.Construct(@ByAge));
    for P in People do
      WriteLn(P.Name, ' ', P.Age);
  finally
    People.Free;
  end;
end.

Ali 27
Ada 34
Mia 34

constref passes the elements without copying them — the comparer's rule. TComparer<T>.Construct turns the function into what Sort takes.

#Writing a generic type

You can write generic types too. The type parameter is a placeholder that the user fills in:

program Generic;

{$mode objfpc}{$H+}
{$modeswitch advancedrecords}

type
  generic TRange<T> = record
    Low, High: T;
    function Contains(const X: T): Boolean;
  end;

function TRange.Contains(const X: T): Boolean;
begin
  Result := (X >= Low) and (X <= High);
end;

type
  TIntRange = specialize TRange<Integer>;
  TTextRange = specialize TRange<string>;

var
  R: TIntRange;
  T: TTextRange;
begin
  R.Low := 1;
  R.High := 10;
  WriteLn('5 in 1..10: ', R.Contains(5), '; 11: ', R.Contains(11));
  T.Low := 'b';
  T.High := 'm';
  WriteLn('"fig" in b..m: ', T.Contains('fig'));
end.

5 in 1..10: TRUE; 11: FALSE
"fig" in b..m: TRUE

The record has methods — Free Pascal calls them advanced records, and {$modeswitch advancedrecords} under the mode line turns them on.

#In Pocket: the list of entries

Pocket keeps its entries in a TObjectList of TEntry with methods of its own — totals, a month, the categories. Here is the whole unit, src/pocketentries.pas; TEntry is the class from chapter 8, with an Assign that copies another entry's values:

{ The entries of Pocket: every expense and income, and the list of them.

    Entries := TEntryList.Create;
    Entries.AddEntry(EncodeDate(2026, 11, 3), ekExpense, 'Food', 12.50, 'Lunch');
    WriteLn(FormatMoney(Entries.Balance));

  Handbook: chapter 5 (enumerations), chapter 8 (classes), chapter 10 (generics). }
unit PocketEntries;

{$mode objfpc}{$H+}

interface

uses
  SysUtils, Generics.Collections;

type
  TEntryKind = (ekExpense, ekIncome);

  { One expense or income. }
  TEntry = class
  private
    FId: Int64;
    FDate: TDateTime;
    FKind: TEntryKind;
    FCategory: string;
    FAmount: Currency;
    FNote: string;
    procedure SetAmount(AValue: Currency);
  public
    { A copy of another entry's values. }
    procedure Assign(Other: TEntry);
    { The amount with its sign: an expense is negative. }
    function SignedAmount: Currency;
    { 0 until a store gives it one. }
    property Id: Int64 read FId write FId;
    property Date: TDateTime read FDate write FDate;
    property Kind: TEntryKind read FKind write FKind;
    property Category: string read FCategory write FCategory;
    { Always positive; EArgumentException otherwise. }
    property Amount: Currency read FAmount write SetAmount;
    property Note: string read FNote write FNote;
  end;

  { Entries, newest first after Sort. Owns them: freeing the list frees them. }
  TEntryList = class(specialize TObjectList<TEntry>)
  public
    { A new entry, added to the list. }
    function AddEntry(ADate: TDateTime; AKind: TEntryKind; const ACategory: string;
      AnAmount: Currency; const ANote: string = ''): TEntry;
    function Income: Currency;
    function Expenses: Currency;
    { Income minus expenses. }
    function Balance: Currency;
    { The entries of one month, in a new list that does not own them (they
      stay this list's). The caller frees the new list. }
    function InMonth(Year, Month: Word): TEntryList;
    { The categories used, each once, in alphabetical order. }
    function Categories: TStringArray;
    { The entry with this id; nil when there is none. }
    function FindById(AId: Int64): TEntry;
    { Newest first; on the same day, the one added later first. }
    procedure SortByDate;
  end;

{ 'expense' / 'income', for files and the command line. }
function KindName(Kind: TEntryKind): string;
function TryParseKind(const S: string; out Kind: TEntryKind): Boolean;

implementation

uses
  Classes, DateUtils, Generics.Defaults;

function KindName(Kind: TEntryKind): string;
begin
  case Kind of
    ekExpense: Result := 'expense';
    ekIncome: Result := 'income';
  end;
end;

function TryParseKind(const S: string; out Kind: TEntryKind): Boolean;
begin
  Result := True;
  case LowerCase(Trim(S)) of
    'expense', 'e', '-': Kind := ekExpense;
    'income', 'i', '+': Kind := ekIncome;
  else
    Kind := ekExpense;
    Result := False;
  end;
end;

{ ---- TEntry ---- }

procedure TEntry.SetAmount(AValue: Currency);
begin
  if AValue < 0 then
    raise EArgumentException.CreateFmt('an amount is never negative (%s): the kind says expense or income',
      [CurrToStr(AValue)]);
  FAmount := AValue;
end;

procedure TEntry.Assign(Other: TEntry);
begin
  FId := Other.Id;
  FDate := Other.Date;
  FKind := Other.Kind;
  FCategory := Other.Category;
  FAmount := Other.Amount;
  FNote := Other.Note;
end;

function TEntry.SignedAmount: Currency;
begin
  if FKind = ekExpense then
    Result := -FAmount
  else
    Result := FAmount;
end;

{ ---- TEntryList ---- }

function TEntryList.AddEntry(ADate: TDateTime; AKind: TEntryKind; const ACategory: string;
  AnAmount: Currency; const ANote: string): TEntry;
begin
  Result := TEntry.Create;
  try
    Result.Date := ADate;
    Result.Kind := AKind;
    Result.Category := ACategory;
    Result.Amount := AnAmount;       { may raise: then the entry is freed below }
    Result.Note := ANote;
  except
    Result.Free;
    raise;
  end;
  Add(Result);
end;

function TEntryList.Income: Currency;
var
  E: TEntry;
begin
  Result := 0;
  for E in Self do
    if E.Kind = ekIncome then
      Result := Result + E.Amount;
end;

function TEntryList.Expenses: Currency;
var
  E: TEntry;
begin
  Result := 0;
  for E in Self do
    if E.Kind = ekExpense then
      Result := Result + E.Amount;
end;

function TEntryList.Balance: Currency;
begin
  Result := Income - Expenses;
end;

function TEntryList.InMonth(Year, Month: Word): TEntryList;
var
  E: TEntry;
begin
  Result := TEntryList.Create(False);
  for E in Self do
    if (YearOf(E.Date) = Year) and (MonthOf(E.Date) = Month) then
      Result.Add(E);
end;

function TEntryList.Categories: TStringArray;
var
  Names: TStringList;
  E: TEntry;
begin
  Names := TStringList.Create;
  try
    Names.Sorted := True;
    Names.Duplicates := dupIgnore;
    Names.CaseSensitive := False;
    for E in Self do
      if E.Category <> '' then
        Names.Add(E.Category);
    Result := Names.ToStringArray;
  finally
    Names.Free;
  end;
end;

function TEntryList.FindById(AId: Int64): TEntry;
var
  E: TEntry;
begin
  for E in Self do
    if E.Id = AId then
      Exit(E);
  Result := nil;
end;

function CompareNewestFirst(constref A, B: TEntry): Integer;
begin
  if A.Date > B.Date then
    Result := -1
  else if A.Date < B.Date then
    Result := 1
  else if A.Id > B.Id then
    Result := -1
  else if A.Id < B.Id then
    Result := 1
  else
    Result := 0;
end;

procedure TEntryList.SortByDate;
begin
  Sort(specialize TComparer<TEntry>.Construct(@CompareNewestFirst));
end;

end.

What to notice:

  • TEntryList = class(specialize TObjectList<TEntry>) — a class built on a generic one. It is an object list (Add, Count, for … in, owning) and adds Pocket's methods. Inside them, Self is the list.
  • AddEntry makes the entry, and frees it again if setting a value raises (chapter 9): a list never holds a half-made entry, and nothing leaks.
  • InMonth returns a new list made with Create(False): it points to the same entries without owning them. The caller frees only the list.
  • Categories uses a sorted TStringList that ignores doubles, and returns its strings as an array.
  • SortByDate sorts with a comparing function, newest first.

unit PocketReports;

{$mode objfpc}{$H+}
{ Free Pascal 3.2's TDictionary warns about its own enumerators when it is
  specialized ("Constructing a class ... with abstract method"): harmless }
{$WARN 4046 OFF}

interface

uses
  PocketEntries;

type
  TMonthSummary = record
    Year, Month: Word;
    Income, Expenses, Balance: Currency;
    Count: Integer;
  end;

  TCategoryTotal = record
    Category: string;
    Amount: Currency;
    { of all the entries of the kind: 0..100 }
    Percent: Double;
  end;
  TCategoryTotals = array of TCategoryTotal;

{ The income, expenses and balance of one month. }
function MonthSummary(Entries: TEntryList; Year, Month: Word): TMonthSummary;

{ The total of every category of one kind, the biggest first. }
function TotalsByCategory(Entries: TEntryList; Kind: TEntryKind): TCategoryTotals;

implementation

uses
  Generics.Collections;

function MonthSummary(Entries: TEntryList; Year, Month: Word): TMonthSummary;
var
  InMonth: TEntryList;
begin
  Result := Default(TMonthSummary);
  Result.Year := Year;
  Result.Month := Month;
  InMonth := Entries.InMonth(Year, Month);
  try
    Result.Income := InMonth.Income;
    Result.Expenses := InMonth.Expenses;
    Result.Balance := InMonth.Balance;
    Result.Count := InMonth.Count;
  finally
    InMonth.Free;      { only the list: the entries are Entries' }
  end;
end;

function TotalsByCategory(Entries: TEntryList; Kind: TEntryKind): TCategoryTotals;
var
  Sums: specialize TDictionary<string, Currency>;
  E: TEntry;
  Pair: specialize TPair<string, Currency>;
  Sum, All: Currency;
  I, J: Integer;
  T: TCategoryTotal;
begin
  Result := nil;
  All := 0;
  Sums := specialize TDictionary<string, Currency>.Create;
  try
    for E in Entries do
      if E.Kind = Kind then
      begin
        if not Sums.TryGetValue(E.Category, Sum) then
          Sum := 0;
        Sums.AddOrSetValue(E.Category, Sum + E.Amount);
        All := All + E.Amount;
      end;
    for Pair in Sums.ToArray do
    begin
      T.Category := Pair.Key;
      T.Amount := Pair.Value;
      if All > 0 then
        T.Percent := Pair.Value / All * 100
      else
        T.Percent := 0;
      SetLength(Result, Length(Result) + 1);
      Result[High(Result)] := T;
    end;
  finally
    Sums.Free;
  end;
  { the biggest first (a dictionary has no order); a few categories: a simple sort is enough }
  for I := 0 to High(Result) - 1 do
    for J := I + 1 to High(Result) do
      if (Result[J].Amount > Result[I].Amount) or
        ((Result[J].Amount = Result[I].Amount) and (Result[J].Category < Result[I].Category)) then
      begin
        T := Result[I];
        Result[I] := Result[J];
        Result[J] := T;
      end;
end;

end.

TotalsByCategory adds up the amounts per category in a dictionary, then copies them into an array of records and sorts it, biggest first. (Default(TMonthSummary) gives a record with every field zero.)

Put together:

program PocketMonth;

{$mode objfpc}{$H+}

uses
  SysUtils, PocketMoney, PocketEntries, PocketReports;

var
  Entries: TEntryList;
  S: TMonthSummary;
  T: TCategoryTotal;
  E: TEntry;
begin
  Entries := TEntryList.Create;
  try
    Entries.AddEntry(EncodeDate(2026, 11, 1), ekIncome, 'Salary', 3000);
    Entries.AddEntry(EncodeDate(2026, 11, 3), ekExpense, 'Food', 12.50, 'Lunch');
    Entries.AddEntry(EncodeDate(2026, 11, 5), ekExpense, 'Rent', 900);
    Entries.AddEntry(EncodeDate(2026, 11, 9), ekExpense, 'Food', 47.50, 'Market');
    Entries.AddEntry(EncodeDate(2026, 10, 30), ekExpense, 'Food', 20);

    S := MonthSummary(Entries, 2026, 11);
    WriteLn(Format('November: %d entries, balance %s', [S.Count, FormatMoney(S.Balance)]));
    for T in TotalsByCategory(Entries.InMonth(2026, 11), ekExpense) do
      WriteLn(Format('  %-6s %8s %3.0f%%', [T.Category, FormatMoney(T.Amount), T.Percent]));
    WriteLn('Categories: ', string.Join(', ', Entries.Categories));
    Entries.SortByDate;
    E := Entries[0];
    WriteLn('Newest: ', FormatDateTime('yyyy-mm-dd', E.Date), ' ', E.Note);
  finally
    Entries.Free;
  end;
end.

November: 4 entries, balance 2,040.00
  Rent     900.00  94%
  Food      60.00   6%
Categories: Food, Rent, Salary
Newest: 2026-11-09 Market

Something is wrong with this program — it works and prints the right numbers, yet it leaks. Entries.InMonth(…) makes a list, and nobody frees it. MonthSummary frees the one it makes; the for loop here does not. In Pocket's real code (chapter 13) the list goes into a variable and is freed in a finally. Spotting such things is a skill: every function that returns a new object hands over the job of freeing it.
