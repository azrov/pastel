#18. Charts and reports

Numbers in a list answer "how much?"; a picture answers "where did it go?" at a glance. And sooner or later someone wants it on paper: the month for the tax adviser, an Excel file for the bank. This chapter adds Pocket's chart and its two exports.

#TChart

TChart draws bars, lines, pies and donuts. Pocket's is declared in the .pform (chapter 15):

object Spending: TChart
  Kind = ckDonut          // ckBar, ckLine, ckPie, ckDonut
  Title = 'Where it went'
  Width = 300
end

and filled in code: the labels, then one or more series of numbers, one number per label.

Spending.Clear;
Spending.SetLabels(['Rent', 'Food', 'Transport']);
Spending.AddSeries('Expenses', [650, 182.4, 61]);

A pie or a donut shows the first series, one slice per label, and a donut writes the total in its middle. Bars and lines show every series side by side — this year against last year:

Months.Kind := ckBar;
Months.SetLabels(['Sep', 'Oct', 'Nov']);
Months.AddSeries('2025', [1210, 1340, 1190]);
Months.AddSeries('2026', [1105, 1290, 1250]);

The value under the mouse (or the finger) is shown by the chart itself; OnItemClick tells which bar or slice was clicked. ShowValues writes the numbers on it, Stacked puts the bars on top of each other.

In ShowMonth (chapter 16) the chart gets the month's expenses by category, from TotalsByCategory of chapter 10:

    { the chart: the month's expenses by category }
    Labels := nil;
    Values := nil;
    for T in TotalsByCategory(Month, ekExpense) do
    begin
      SetLength(Labels, Length(Labels) + 1);
      Labels[High(Labels)] := T.Category;
      SetLength(Values, Length(Values) + 1);
      Values[High(Values)] := T.Amount;
    end;
  finally
    Month.Free;
  end;
  Spending.Clear;
  if Length(Values) > 0 then
  begin
    Spending.SetLabels(Labels);
    Spending.AddSeries(_('Expenses'), Values);
  end;
  EntriesChange(nil);

TotalsByCategory gives records; the chart wants two arrays. The loop grows each by one — fine for a dozen categories (for thousands, set the length once with SetLength(Labels, Count)). A month with no expenses gets no series: the chart stays empty.

#A PDF report

Pastel.Report makes documents that flow over pages: a title, text, tables, totals. Everything is written from top to bottom; a full page starts a new one, and a table repeats its heads there.

program MonthReport;

{$mode objfpc}{$H+}

uses
  Pastel.Report;

var
  R: TReport;
begin
  R := TReport.Create;                                  // A4, portrait
  try
    R.Footer := 'Pocket · {page} / {pages}';            // on every page
    R.Title('November 2026');
    R.Table(['Date', 'Category', 'Note', 'Amount'], [26, 36, 0, 30], 'LLLR');
    R.Row(['03.11.2026', 'Food', 'Lunch', '-12.50']);
    R.Row(['04.11.2026', 'Rent', '', '-650.00']);
    R.Row(['05.11.2026', 'Salary', 'November', '2,400.00']);
    R.EndTable;
    R.Total('Income', '2,400.00');
    R.Total('Expenses', '662.50');
    R.Total('Balance', '1,737.50', True);                // True: bold
    R.SaveToFile('november.pdf');                       // or .html
  finally
    R.Free;
  end;
end.

Table takes the heads, the widths in millimetres (0: what is left) and how each column is aligned: L, R, C. The cells are text — the report writes what you give it, so you format the numbers (with Money, below).

The letters come from a TrueType font of the system, and only the letters used go into the file: a page is about 30 KB, and ş, ğ, İ, € print right everywhere.

#An Excel file

Pastel.Sheets writes .xlsx files. Unlike the report, it takes values: numbers, dates and True/False go into Excel as such, so the person who opens the file can sum, sort and chart them.

program MonthSheet;

{$mode objfpc}{$H+}

uses
  SysUtils, Pastel.Sheets;

var
  S: TSpreadsheet;
begin
  S := TSpreadsheet.Create('November 2026');            // the sheet's name
  try
    S.Widths([12, 16, 30, 12]);                         // in characters
    S.Row(['Date', 'Category', 'Note', 'Amount'], True);  // True: bold
    S.Row([EncodeDate(2026, 11, 3), 'Food', 'Lunch', -12.5]);
    S.Row([EncodeDate(2026, 11, 4), 'Rent', '', -650.0]);
    S.SaveToFile('november.xlsx');
  finally
    S.Free;
  end;
end.

Row takes an array of const (chapter 10's open arrays): each value keeps its type. A TDateTime is a Double, so EncodeDate goes in as a number Excel shows as a date. ReadSpreadsheet and ReadCsv read such files back — chapter 20 uses them for the bank import.

#Pocket's exports

The PDF and Excel buttons both call ExportMonth with the file's extension. On a computer it asks where to save; on a phone, where there is no such dialog, the file goes into the app's temporary folder:

procedure THomeForm.PdfClick(Sender: TObject);
begin
  ExportMonth('.pdf');
end;

procedure THomeForm.ExportMonth(const Ext: string);
var
  Base: string;
begin
  Base := Format('pocket-%d-%.2d%s', [FYear, FMonth, Ext]);
  if IsMobile then
    { a phone: written into the app's cache, then the share menu (mail, Drive, WhatsApp) }
    ExportTo(nil, True, IncludeTrailingPathDelimiter(GetTempDir) + Base)
  else if Ext = '.pdf' then
    SaveFileDialog(Base, 'PDF|*.pdf', _('Save the report'), '.pdf', @ExportTo)
  else
    SaveFileDialog(Base, 'Excel|*.xlsx', _('Save the list'), '.xlsx', @ExportTo);
end;

SaveFileDialog does not wait (chapter 16): it calls ExportTo with the name chosen. ExportTo then writes one of the two files:

procedure THomeForm.ExportTo(Sender: TObject; Ok: Boolean; const FileName: string);
var
  R: TReport;
  X: TSpreadsheet;
  S: TMonthSummary;
  E: TEntry;
  T: TCategoryTotal;
  Month: TEntryList;
begin
  if not Ok then
    Exit;
  Month := FEntries.InMonth(FYear, FMonth);
  try
    if SameText(ExtractFileExt(FileName), '.pdf') then
    begin
      S := MonthSummary(FEntries, FYear, FMonth);
      R := TReport.Create;
      try
        R.Footer := 'Pocket · {page} / {pages}';
        R.Title(MonthName(FMonth) + ' ' + IntToStr(FYear));
        R.Table([_('Date'), _('Category'), _('Note'), _('Amount')], [26, 36, 0, 30], 'LLLR');
        for E in Month do
          R.Row([FormatDateShort(E.Date), E.Category, E.Note, Money(E.SignedAmount)]);
        R.EndTable;
        R.Total(_('Income'), Money(S.Income));
        R.Total(_('Expenses'), Money(S.Expenses));
        R.Total(_('Balance'), Money(S.Balance), True);
        R.Heading(_('Where it went'));
        R.Table([_('Category'), _('Amount'), '%'], [0, 30, 20], 'LRR');
        for T in TotalsByCategory(Month, ekExpense) do
          R.Row([T.Category, Money(T.Amount), Format('%.0f', [T.Percent])]);
        R.EndTable;
        R.SaveToFile(FileName);
      finally
        R.Free;
      end;
    end
    else
    begin
      X := TSpreadsheet.Create(MonthName(FMonth) + ' ' + IntToStr(FYear));
      try
        X.Widths([12, 16, 30, 12]);
        X.Row([_('Date'), _('Category'), _('Note'), _('Amount')], True);
        for E in Month do
          X.Row([E.Date, E.Category, E.Note, Double(E.SignedAmount)]);
        X.SaveToFile(FileName);
      finally
        X.Free;
      end;
    end;
  finally
    Month.Free;
  end;
  if IsMobile then
    ShareFile(FileName)
  else
    OpenDocument(FileName);
end;

Look at the difference between the two branches. The report gets texts, formatted for a person to read: FormatDateShort(E.Date), Money(E.SignedAmount). The sheet gets values: E.Date, Double(E.SignedAmount) — Excel formats them in the reader's own language.

At the end the file is opened: OpenDocument (from Pastel.Print) starts the system's program for it — a PDF viewer, Excel or LibreOffice. On a phone, ShareFile opens the share menu (mail, Drive, a messenger), the way phone apps hand files on. PrintFile(FileName) would send the PDF straight to the printer.

Month is a list that InMonth made for this method, so the method frees it — in a finally, because a full disk makes SaveToFile raise an exception.

#Exercises

  1. Make the chart a bar chart of the last six months' expenses (one label per month, one series).
  2. Add a second table to the report: the income by category.
  3. Add a column Kind to the Excel file, with Expense or Income, and a second sheet with the totals by category (AddSheet).
