#2. Values, types and variables

A program works with values: numbers, text, true or false. In Pascal every value has a type, and the compiler checks that types fit together before the program runs. This catches many mistakes early — adding a word to a number, or putting a fraction where only whole numbers belong.

#Variables

A variable is a named place for a value. You declare it in a var section, with its type, before the begin that uses it; then := puts a value into it:

program Variables;

{$mode objfpc}{$H+}

var
  Count: Integer;
  Price: Double;
  Name: string;
  Paid: Boolean;
begin
  Count := 3;
  Price := 4.5;
  Name := 'Tea';
  Paid := False;
  WriteLn(Name, ': ', Count, ' cups');
  Count := Count + 1;              // the old value, plus one
  WriteLn(Name, ': ', Count, ' cups');
  WriteLn('Paid: ', Paid);
end.

Tea: 3 cups
Tea: 4 cups
Paid: FALSE

Remember the two signs: := puts a value into a variable, = compares (if Count = 3 then …). Several variables of one type can share a line: A, B, C: Integer;.

Give variables names that say what they hold — Total, CustomerName, IsPaid — not x or tmp. Code is read far more often than it is written.

A variable inside a procedure (chapter 4) has no value until you give it one. The compiler warns you when you use one too early: read the warnings, they are usually right.

#Whole numbers

Type Holds
Integer −2,147,483,648 to 2,147,483,647 the everyday whole number
Int64 about ±9.2 × 10¹⁸ big counts, ids, file sizes
Byte 0 to 255 one byte of a file, a color channel
Word 0 to 65,535 a year, a month
Cardinal 0 to 4,294,967,295 only positive

Low and High tell the smallest and biggest value of a type:

program Ranges;

{$mode objfpc}{$H+}

begin
  WriteLn('Integer: ', Low(Integer), ' .. ', High(Integer));
  WriteLn('Byte:    ', Low(Byte), ' .. ', High(Byte));
  WriteLn('Int64:   ', High(Int64));
end.

Integer: -2147483648 .. 2147483647
Byte:    0 .. 255
Int64:   9223372036854775807

#Arithmetic

program Arithmetic;

{$mode objfpc}{$H+}

var
  A, B: Integer;
begin
  A := 17;
  B := 5;
  WriteLn('A + B   = ', A + B);
  WriteLn('A - B   = ', A - B);
  WriteLn('A * B   = ', A * B);
  WriteLn('A div B = ', A div B, '   (whole division)');
  WriteLn('A mod B = ', A mod B, '   (what is left)');
  Inc(A);                          // A := A + 1
  Dec(B, 2);                       // B := B - 2
  WriteLn('A = ', A, ', B = ', B);
  WriteLn('2 + 3 * 4   = ', 2 + 3 * 4);
  WriteLn('(2 + 3) * 4 = ', (2 + 3) * 4);
end.

A + B   = 22
A - B   = 12
A * B   = 85
A div B = 3   (whole division)
A mod B = 2   (what is left)
A = 18, B = 3
2 + 3 * 4   = 14
(2 + 3) * 4 = 20

div divides whole numbers and drops the rest; mod gives the rest. / always gives a real number, even for 6 / 3 — so the compiler refuses A := 6 / 3 when A is an Integer. Multiplication and division go before addition and subtraction; brackets change the order.

#Real numbers

Double holds numbers with a fraction: 3.14, 0.001, -2.5e6 (−2.5 million). It is fast and precise to about 15 digits — but it stores numbers in binary, and most decimal fractions cannot be stored exactly:

program Fractions;

{$mode objfpc}{$H+}

uses
  SysUtils;

var
  D: Double;
  C: Currency;
begin
  D := 0.1 + 0.2;
  WriteLn('Double:   0.1 + 0.2 = 0.3 is ', D = 0.3);
  WriteLn('          it is ', FloatToStr(D));
  C := 0.1;
  C := C + 0.2;
  WriteLn('Currency: 0.1 + 0.2 = 0.3 is ', C = 0.3);
  WriteLn('Round(2.5) = ', Round(2.5), ', Round(3.5) = ', Round(3.5));
  WriteLn('Trunc(2.9) = ', Trunc(2.9));
end.

Double:   0.1 + 0.2 = 0.3 is FALSE
          it is 0.3
Currency: 0.1 + 0.2 = 0.3 is TRUE
Round(2.5) = 2, Round(3.5) = 4
Trunc(2.9) = 2

FloatToStr rounds what it shows, so D looks like 0.3 — but it is 0.30000000000000004, and the comparison says so. For money use Currency: it keeps exactly four decimal places, so cents never drift. Pocket keeps every amount as a Currency.

Two more surprises in that output: Round rounds a half to the even number (2.5 → 2, 3.5 → 4: "banker's rounding", which keeps sums of many rounded numbers fair), and Trunc just cuts the fraction off.

#True or false

A Boolean is True or False. Comparisons make them, and and, or, not combine them:

program Logic;

{$mode objfpc}{$H+}

var
  Age: Integer;
  HasTicket, MayEnter: Boolean;
begin
  Age := 17;
  HasTicket := True;
  MayEnter := (Age >= 18) and HasTicket;
  WriteLn('May enter: ', MayEnter);
  WriteLn('Too young: ', not (Age >= 18));
  WriteLn('Ticket or adult: ', HasTicket or (Age >= 18));
end.

May enter: FALSE
Too young: TRUE
Ticket or adult: TRUE

The brackets are needed. and binds stronger than >=, so Age >= 18 and HasTicket means Age >= (18 and HasTicket) — the compiler refuses it. Put brackets around every comparison you combine.

#Letters and text

A Char is one character ('A'), a string is text of any length. + joins strings:

program Texts;

{$mode objfpc}{$H+}

var
  First, Last, Full: string;
  Initial: Char;
begin
  First := 'Ada';
  Last := 'Lovelace';
  Full := First + ' ' + Last;
  Initial := First[1];             // the first character: strings count from 1
  WriteLn(Full);
  WriteLn('Initials: ', Initial, '.', Last[1], '.');
  WriteLn('Letters in the name: ', Length(Full));
end.

Ada Lovelace
Initials: A.L.
Letters in the name: 12

Chapter 6 is about text: it has more to say, especially about letters like ş and ü.

#Constants

A value that never changes gets a name in a const section. The name says what the number means, and changing it later is one edit instead of many:

program Constants;

{$mode objfpc}{$H+}

uses
  SysUtils;

const
  VatRate = 20;                    // percent
  ShopName = 'Corner Café';

var
  Net: Currency;
begin
  Net := 250;
  WriteLn(ShopName);
  WriteLn('VAT: ', CurrToStr(Net * VatRate / 100));
end.

Corner Café
VAT: 50

#From one type to another

Pascal does not change types behind your back: an Integer does not become a string by itself. The SysUtils unit has the functions that convert (add uses SysUtils; after the directives, as in the program above):

From To
IntToStr(42) '42'
StrToInt('42') 42 an exception (chapter 9) when it is not a number
StrToIntDef('x', 0) 0 a default instead
TryStrToInt('42', N) True, N = 42 the safe way for user input
FloatToStr(2.5) '2.5'
CurrToStr(Price) '4.5'
Round(2.7), Trunc(2.7) 3, 2 real to whole
Ord('A'), Chr(65) 65, 'A' a character's number and back

An Integer becomes a Double by itself where one is needed (no value is lost); the other way needs Round or Trunc.

#Format

Format builds text from a pattern and values, and controls how numbers look:

program Formats;

{$mode objfpc}{$H+}

uses
  SysUtils;

var
  Name: string;
  Qty: Integer;
  Price: Double;
begin
  Name := 'Coffee';
  Qty := 3;
  Price := 2.5;
  WriteLn(Format('%s x %d = %.2f', [Name, Qty, Qty * Price]));
  WriteLn(Format('[%5d] [%-8s] [%8.3f]', [42, 'left', 3.14159]));
  WriteLn(Format('%.1f%%', [12.345]));
end.

Coffee x 3 = 7.50
[   42] [left    ] [   3.142]
12.3%

%s is a string, %d a whole number, %f a real number (%.2f: two decimals), %% a percent sign. A number before the letter is the width (%5d), a minus aligns to the left. The values go between [ ].

Format writes numbers the computer's way when it has a FormatSettings that says so; Pastel programs write a dot unless told otherwise. Chapter 19 shows numbers in the user's language.

#In Pocket

Pocket will keep amounts as Currency and show them like 1,234.50. Here is the first piece — a program that adds up a few expenses:

program FirstTotal;

{$mode objfpc}{$H+}

uses
  SysUtils;

var
  Lunch, Bus, Book, Total: Currency;
begin
  Lunch := 12.50;
  Bus := 2.75;
  Book := 18.90;
  Total := Lunch + Bus + Book;
  WriteLn(Format('Spent today: %.2f', [Double(Total)]));
end.

Spent today: 34.15

Format's %f takes a real number, so Double(Total) hands it the Currency as one — a type cast: "treat this value as that type".

#Exercises

  1. Declare your age in a variable and print how many days old you are, roughly (* 365).
  2. Print 7 / 2, 7 div 2 and 7 mod 2. Explain each.
  3. Ask for a price with ReadLn into a string, convert it with StrToFloat, and print it with 20% added.
  4. ★ Use TryStrToInt to read a number from the user; when it is not one, print That is not a number. (You need if, from the next chapter: if TryStrToInt(S, N) then … else ….)
