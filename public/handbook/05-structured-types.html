#5. Arrays, records, enumerations and sets

So far every variable held one value. Real data comes in groups: the expenses of a month, the parts of an address, the days a shop is open. This chapter shows Pascal's ways of building types out of other types.

New types are named in a type section, which comes before var:

type
  TAmounts = array of Currency;

By custom, type names start with T.

#Arrays

An array is a row of values of one type, reached by number.

#Fixed size

program Week;

{$mode objfpc}{$H+}

uses
  SysUtils;

const
  DayNames: array[1..7] of string = ('Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun');

var
  Spent: array[1..7] of Currency;
  Day: Integer;
  Total: Currency;
begin
  Spent[1] := 32.50;
  Spent[2] := 18;
  Spent[3] := 55.20;
  Spent[4] := 12;
  Spent[5] := 41;
  Spent[6] := 0;
  Spent[7] := 26.75;
  Total := 0;
  for Day := Low(Spent) to High(Spent) do
  begin
    WriteLn(Format('%s %6.2f', [DayNames[Day], Double(Spent[Day])]));
    Total := Total + Spent[Day];
  end;
  WriteLn(Format('    %6.2f', [Double(Total)]));
end.

Mon  32.50
Tue  18.00
Wed  55.20
Thu  12.00
Fri  41.00
Sat   0.00
Sun  26.75
    185.45

array[1..7] says which numbers the elements have; Low and High give them back, so loops never go wrong when the range changes. A debug build stops the program with an error when an index is outside the range — a bug found early instead of strange values later.

#Dynamic arrays

When the number of elements is known only while the program runs, use a dynamic array. It starts empty; SetLength gives it a size, and it always counts from 0:

program Dynamic;

{$mode objfpc}{$H+}

var
  Numbers: array of Integer;
  I, N: Integer;
begin
  SetLength(Numbers, 5);
  for I := 0 to High(Numbers) do
    Numbers[I] := (I + 1) * 10;

  { one more at the end }
  SetLength(Numbers, Length(Numbers) + 1);
  Numbers[High(Numbers)] := 99;

  Insert(15, Numbers, 1);          // 15 at index 1
  Delete(Numbers, 0, 1);           // remove 1 element at index 0

  for N in Numbers do
    Write(N, ' ');
  WriteLn;
  WriteLn('Elements: ', Length(Numbers));
end.

15 20 30 40 50 99
Elements: 6

Length is the number of elements, High the last index (Length - 1; −1 when empty). The memory is freed by itself when the array is no longer used.

for … in walks through every element without an index — use it whenever you do not need the index.

Growing an array one element at a time is fine for tens or hundreds of elements. For many thousands, the lists of chapter 10 grow more cleverly.

#Array parameters and literals

A parameter declared array of Integer takes any array of integers — fixed or dynamic — and also a list written in brackets:

program OpenArrays;

{$mode objfpc}{$H+}

function Sum(const Values: array of Integer): Integer;
var
  V: Integer;
begin
  Result := 0;
  for V in Values do
    Inc(Result, V);
end;

var
  Some: array of Integer;
begin
  WriteLn(Sum([1, 2, 3, 4]));
  Some := [10, 20, 30];
  WriteLn(Sum(Some));
  WriteLn(Sum([]));
end.

10
60
0

Inside such a routine the elements are numbered from 0, whatever the caller's array used.

#Records

A record groups values of different types that belong together — one thing with several parts:

program Records;

{$mode objfpc}{$H+}

uses
  SysUtils;

type
  TExpense = record
    Day: TDateTime;
    Category: string;
    Amount: Currency;
  end;

var
  E, Copy_: TExpense;
begin
  E.Day := EncodeDate(2026, 11, 3);
  E.Category := 'Food';
  E.Amount := 12.50;
  Copy_ := E;                      // all the fields are copied
  Copy_.Amount := 99;
  WriteLn(Format('%s %s %.2f', [FormatDateTime('yyyy-mm-dd', E.Day), E.Category, Double(E.Amount)]));
  WriteLn('The copy: ', CurrToStr(Copy_.Amount), ', the original: ', CurrToStr(E.Amount));
end.

2026-11-03 Food 12.50
The copy: 99, the original: 12.5

Assigning a record copies it: the two variables are separate afterwards. (Objects, in chapter 8, behave differently — remember this.)

TDateTime is how Pascal keeps a moment: a Double counting days since 30 December 1899, the fraction being the time of day. EncodeDate makes one, FormatDateTime writes it, Date is today and Now this moment.

#Enumerations

An enumeration is a type with a fixed list of named values. Instead of a number or a string that "means" something, the meaning is in the type, and the compiler checks it:

program Enums;

{$mode objfpc}{$H+}

type
  TEntryKind = (ekExpense, ekIncome);
  TWeekday = (Mon, Tue, Wed, Thu, Fri, Sat, Sun);

const
  KindNames: array[TEntryKind] of string = ('expense', 'income');

var
  K: TEntryKind;
  D: TWeekday;
begin
  K := ekIncome;
  WriteLn('The kind: ', KindNames[K]);
  case K of
    ekExpense: WriteLn('Money goes out.');
    ekIncome: WriteLn('Money comes in.');
  end;
  for D := Mon to Fri do
    Write(Ord(D), ' ');
  WriteLn;
  WriteLn('After Fri comes day number ', Ord(Succ(Fri)));
end.

The kind: income
Money comes in.
0 1 2 3 4
After Fri comes day number 5
  • The values often get a short prefix (ek for entry kind), so their names never clash with others.
  • An array can be indexed by an enumeration: array[TEntryKind] of string has one element per kind — add a kind and the compiler reminds you of every such array that needs one more element.
  • Ord gives the position (from 0), Succ and Pred the next and the previous value; enumerations work in for and case.

#Sets

A set holds some of the values of an enumeration (or of small numbers, or characters) — each one is in it or not:

program Sets;

{$mode objfpc}{$H+}

type
  TWeekday = (Mon, Tue, Wed, Thu, Fri, Sat, Sun);
  TWeekdays = set of TWeekday;

const
  Names: array[TWeekday] of string = ('Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun');

var
  Open: TWeekdays;
  D: TWeekday;
begin
  Open := [Mon..Fri];
  Exclude(Open, Wed);              // closed on Wednesdays
  Include(Open, Sat);
  for D in TWeekday do
    if D in Open then
      Write(Names[D], ' ');
  WriteLn;
  if Sun in Open then
    WriteLn('Open on Sunday')
  else
    WriteLn('Closed on Sunday');
  if ['a'..'z'] * ['x', '1'] = ['x'] then
    WriteLn('Of x and 1 only x is a small letter.');
end.

Mon Tue Thu Fri Sat
Closed on Sunday
Of x and 1 only x is a small letter.

in asks whether a value is in the set; + joins two sets, * keeps what both have, - takes away. A test like C in ['0'..'9'] is shorter and faster than four comparisons.

#In Pocket

With these types, Pocket's data has a shape: an entry is a record, its kind an enumeration, and the month a dynamic array of entries.

program Entries;

{$mode objfpc}{$H+}

uses
  SysUtils;

type
  TEntryKind = (ekExpense, ekIncome);

  TEntry = record
    Day: TDateTime;
    Kind: TEntryKind;
    Category: string;
    Amount: Currency;
  end;

  TEntries = array of TEntry;

procedure Add(var List: TEntries; ADay: TDateTime; AKind: TEntryKind; const ACategory: string;
  AnAmount: Currency);
begin
  SetLength(List, Length(List) + 1);
  with List[High(List)] do
  begin
    Day := ADay;
    Kind := AKind;
    Category := ACategory;
    Amount := AnAmount;
  end;
end;

function Total(const List: TEntries; Kind: TEntryKind): Currency;
var
  E: TEntry;
begin
  Result := 0;
  for E in List do
    if E.Kind = Kind then
      Result := Result + E.Amount;
end;

var
  Month: TEntries;
begin
  Add(Month, EncodeDate(2026, 11, 1), ekIncome, 'Salary', 3000);
  Add(Month, EncodeDate(2026, 11, 3), ekExpense, 'Food', 12.50);
  Add(Month, EncodeDate(2026, 11, 5), ekExpense, 'Rent', 900);
  WriteLn('Income:   ', Format('%8.2f', [Double(Total(Month, ekIncome))]));
  WriteLn('Expenses: ', Format('%8.2f', [Double(Total(Month, ekExpense))]));
  WriteLn('Balance:  ', Format('%8.2f', [Double(Total(Month, ekIncome) - Total(Month, ekExpense))]));
end.

Income:    3000.00
Expenses:   912.50
Balance:   2087.50

with List[High(List)] do lets the statements inside name the fields of that element directly. Use with only for short blocks like this one: in a long block it is hard to see which name belongs to what.

List is a var parameter in Add (the procedure changes the caller's array) and a const one in Total (only read, and not copied).

  1. Keep the marks of a class in an array of Integer and print the average, the highest and the lowest.
  2. Make a record TAddress (street, city, postcode) and a procedure that prints one on three lines.
  3. Make an enumeration of the seasons and a function that gives the season of a month (1..12) with case.
