#The Pastel Handbook

Object Pascal from your first line to your first app — on computers and phones.

This handbook teaches two things together: the Object Pascal language, from the beginning to an intermediate level, and Pastel, the toolkit that turns Pascal programs into command-line tools, desktop apps and Android apps. You need no earlier Pascal. If you have written some code in another language, the first chapters will go quickly; if this is your first language, take them slowly and do the exercises.

Every chapter builds on the one before, and the whole book builds one program: Pocket, a small money tracker. You write down what you spend and earn; Pocket tells you where the money goes. It starts as a few lines on the command line and ends as an app with a database, charts, PDF reports, two languages and an Android package.

Every complete program in this book is compiled and run whenever Pastel changes, and its output is checked against what the book says it prints (tests/handbook.py). The finished Pocket is in the repository: examples/pocket-core (the shared part), examples/pocket-cli (the command line) and examples/pocket-app (the app).

#How to read it

  • Type the examples yourself. Copying is faster, but typing is how the language gets into your fingers.
  • Run everything. Change a number, break a line on purpose, read what the compiler says.
  • Do the exercises. Each chapter ends with a few; they are small, and the ones marked ★ go a step further.
  • Keep the reference close. When the book shows one control or one function, the documentation shows them all.

You need Pastel installed (Getting started) and, best, VS Code with Pastel's extension: it colors the code, completes names, shows mistakes as you type and has the form designer.
