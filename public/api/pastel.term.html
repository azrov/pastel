#Pastel.Term

Terminal output and input for console programs.

WriteLn(Green('done'), ' in ', Bold('2.1s'));
T := TTable.Create(['Name', 'Size']);
T.AddRow(['report.pdf', '1.2 MB']);
T.Print;
if Confirm('Delete 3 files?') then ...
Name := Ask('Your name', 'Ali');

Colors are switched off automatically when the output is not a terminal (a pipe or a file), when NO_COLOR is set, or on old Windows consoles. Prompts read from standard input, so they also work in scripts and tests.

uses Pastel.Term; · source: framework/src/pastel.term.pas
