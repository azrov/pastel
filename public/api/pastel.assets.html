#Pastel.Assets

The files of a project's assets/ folder, inside the program.

Logo.FileName := 'logo.png';            // TImage finds assets by name
S := OpenAsset('data/cities.json');     // any file, as a stream
try ... finally S.Free; end;

"pastel build" compiles every file below assets/ into the program (in release builds; debug builds read them from the folder, so changes show without a rebuild). Names use / and are relative to assets/. Conventions: assets/icon.png is the window icon; assets/font.ttf and assets/font-bold.ttf replace the system font.

uses Pastel.Assets; · source: framework/src/pastel.assets.pas
