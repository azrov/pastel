#Pastel.UI

Controls, layout and input handling.

Controls are TComponent descendants with published properties, so they can be created from .pform files the same way Delphi creates forms from .dfm. Layout is a small flexbox-style model: TColumn and TRow place children one after another, Grow shares the free space, Align/Justify position them.

uses Pastel.UI; · source: framework/src/pastel.ui.pas
