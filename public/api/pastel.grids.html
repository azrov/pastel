#Pastel.Grids

Tables and trees.

object People: TGrid
  Editable = True
  object NameColumn: TGridColumn
    Title = 'Name'
  end
  object AgeColumn: TGridColumn
    Title = 'Age'
    Width = 80
    Alignment = Right
  end
end

People.AddRow(['Ayşe', '34']);
People.LoadJson(Db.Query('select name, age from people', []));   // by Field or Title
People.Cells[1, 0] := '35';

Only the rows that show are drawn, so a grid handles many thousands of rows. A click on a title sorts by that column; with Editable, F2, Enter, a double click or typing edits a cell (OnCellEdit can check the value). TListView is a grid for choosing rows, TTreeView a tree of texts:

object Folders: TTreeView
  Items = ('Documents', '  Letters', '  Bills', 'Pictures')
end

#TGridColumnKind

type TGridColumnKind = (gkText, gkNumber, gkMoney, gkDate, gkCheck, gkIcon)

What a column holds. The cells keep the value as data ('1380.6', '2026-11-03', '1'); the column shows it the way the language writes it, sorts it as what it is, and gives it to ToJson as a number or true/false. gkCheck: a check box (a click or Space changes it in an Editable grid); gkIcon: the cell is the name of an icon (Pastel.Icons).
