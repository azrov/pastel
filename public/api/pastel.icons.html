#Pastel.Icons

Icons: small line drawings for buttons, drawn at any size and in any color, so they are sharp on every screen and right in the dark theme.

object SaveButton: TButton
  Icon = 'save'
  Text = 'Save'
end

The built-in ones are listed by IconNames. Your own are drawn on a 24 x 24 grid, one command per part, the parts separated by ';':

l x1 y1 x2 y2 ...      lines through the points
o cx cy r              a circle
f cx cy r              a filled circle (a dot)
a cx cy r from to      an arc; angles in degrees, 0 = right, 90 = down

RegisterIcon('bell', 'l 6 17 6 10; a 12 10 6 180 360; l 18 10 18 17; l 4 17 20 17; f 12 20 1.5');

An icon can also be a picture: a PNG, JPEG or BMP file in assets/ (or next to the program), drawn in its own colors and fitted into the icon's square:

object LogoButton: TButton
  Icon = 'icons/logo.png'
end

#DrawIcon

function DrawIcon(C: TCanvas32; const Name: string; X: Integer; Y: Integer; Size: Integer; Color: TColor32): Boolean

Draws the icon Name in the square X, Y, Size; False when there is no such icon.

#HasIcon

function HasIcon(const Name: string): Boolean

An icon with this name exists.

#RegisterIcon

procedure RegisterIcon(const Name: string; const Drawing: string)

Adds (or replaces) an icon, drawn with the commands above.

#IconNames

function IconNames: TStringArray

The names of all icons, sorted.

#IconDrawing

function IconDrawing(const Name: string): string

The drawing commands of a built-in or registered icon, '' when there is none.

#IsPictureName

function IsPictureName(const Name: string): Boolean

Name is a picture file ('icons/logo.png'): .png, .jpg, .jpeg or .bmp.

#LoadAppPicture

function LoadAppPicture(const FileName: string; Bitmap: TBitmap32): Boolean

Loads a picture of the app: a full path, a file next to the program or in its assets/ folder, or an asset compiled into the program. False when it cannot be found or read.
