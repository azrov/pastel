#Pastel.Java

Java from Pascal: any class of Android (or of the app's own Java files, or of a Java library on a computer), called by its name.

"pastel java add android.widget.Toast" writes typed Pascal for the classes you name (src/java/javaclasses.pas, like Delphi's Java2OP): JToast.makeText(JavaActivity, 'Saved', JToast.LENGTH_SHORT).show;

Underneath, and for calls of your own, this unit: S := JavaStaticStr('android.os.Build', 'MODEL', ''); // a static field N := JavaCallI(Obj, 'java.lang.String', 'length', '()I', []); // a method L := JavaNew('java.util.ArrayList', '()V', []); // a new object The signature is Java's ('(Ljava/lang/String;I)V'); Pascal strings become java.lang.String, objects are passed as TJavaObject.Handle.

Objects are TJavaObject: a reference Java keeps alive until Pascal no longer uses it (freed by itself, like a string). A Java exception becomes an EJavaError with Java's message.

Where Java runs: Android the app's own Java (Pastel's activity); any thread. Android's views and Toast want the UI thread: JavaRunOnUiThread. Computers a Java VM started the first time (JAVA_HOME, else the java of the PATH; PASTEL_JVM: the path of libjvm / jvm.dll). Its class path: PASTEL_JAVA_CLASSPATH, else the project's own Java (build/java, written by "pastel java") and java/ beside the program (its .jar files): Java libraries in desktop apps.

#TJavaObject

type TJavaObject = record

A Java object; Pascal keeps it alive while it is used (a global reference).
Ref: IJavaRef
function Handle: Pointer Java's handle (jobject) for calls; nil for null
function IsNull: Boolean
function ToString: string java.lang.Object's toString
function JavaClassName: string its class's name: 'android.widget.Toast'
function IsInstanceOf(const AClass: string): Boolean
function AsInteger: Integer a boxed value's (java.lang.Integer, Long, Boolean, Double, Character...): 0, False, '' for null
function AsInt64: Int64
function AsBoolean: Boolean
function AsDouble: Double
function AsString: string

#Other types
type TJavaUiProc = procedure
type TJavaArgs = array of TJavaObject
type TJavaCallbackEvent = procedure(Method: string; Args: TJavaArgs; Answer: TJavaObject) a call of an interface's method that Pascal does (JavaImplement): the method's name, its arguments (numbers boxed: Args[0].AsInteger) and what to answer (left null: null, 0 or False; a number boxed: JavaInteger(1))

#JavaRunOnUiThread

procedure JavaRunOnUiThread(Proc: TJavaUiProc)

Runs Proc on Android's UI thread (views, Toast), later, without waiting; at once elsewhere. It must not touch Pastel's forms (they live on the app's own thread).

#JavaImplement

function JavaImplement(const InterfaceName: string; Handler: TJavaCallbackEvent; OnAppThread: Boolean = True): TJavaObject

An object of a Java interface (a listener, a Runnable, a Comparator) whose methods are done by Handler: Button.setOnClickListener(JavaImplement('android.view.View$OnClickListener', @Clicked)); OnAppThread: Handler runs on the app's own thread, where Pastel's forms can be used (a method that answers nothing does not wait for it); False: on Java's thread that called, at once. The object lives while the program does.

#JavaCallbackSignature

function JavaCallbackSignature: string

Inside a handler of JavaImplement: Java's signature of the method called, '(Landroid/view/View;I)V' - for an interface with two methods of one name.
