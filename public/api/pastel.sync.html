#Pastel.Sync

Data that works offline and is synchronized with a server: the desktop (or phone) keeps its own SQLite file, works without a network, and exchanges the changes with the server when it can.

Store := TSyncStore.Create(TDatabase.Open('sqlite:shop.db'), True);
Store.AddTable('customers', 'name varchar(200) not null, ' +
  'phone varchar(50) not null default '''', notes text');
Store.OnCheck := @CheckRecord;                 // raise ESyncInvalid for wrong values
Store.CreateTables;

Id := Store.Save('customers', JObject(['name', 'Ayşe Yılmaz']));   // a new id; checked
Rows := Store.List('customers', 'lower(name) like ?', ['%ayşe%'], 'name');
Store.Delete('customers', Id);                 // marked, so the deletion travels too

R := SyncWithServer(Store, 'https://shop.example.com', ApiKey, LastSync);   // the client
AddSyncRoute(Web, ServerStore);                // the server (Pastel.SyncWeb): POST /api/sync

How it works: every record gets its id where it is made (16 random characters, so computers never clash), and updated_at, the time of its last change (UTC, sortable as text). A client marks what it changes (dirty), sends it, and takes what the server got from others since its last sync. When a record was changed on both sides, the newer change wins; sending the same records twice changes nothing. Records are never really deleted, only marked (deleted = 1). The server's clock decides what is new for a client (synced_at), so clocks of the computers may be wrong.

The salon example (examples/salon-core) is built on it.

#Routines

#SyncStamp

function SyncStamp: string

The current time as records are stamped: '2026-11-01T09:30:00.123000Z'; always larger than the one before, also in the same millisecond.

#NewSyncId

function NewSyncId: string

A new id: 16 random characters.

#SyncWithServer

function SyncWithServer(Store: TSyncStore; const Url: string; const ApiKey: string; var LastSync: string; const Path: string = '/api/sync'): TSyncResult

A client's sync: sends what changed here to Url + Path (POST, JSON), takes what changed there. LastSync: the server's time of the last sync, kept by the caller ('' the first time). EHttpError when the server cannot be reached; nothing is lost, the changes go next time.

#AnswerSync

function AnswerSync(Store: TSyncStore; Request: TJSONObject): TJSONObject

What the server does with a sync request: {"since": "...", "changes": {...}} -> {"now": "...", "applied": 2, "changes": {...}} (Pastel.SyncWeb uses it).
