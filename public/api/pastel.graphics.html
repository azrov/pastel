#Pastel.Graphics

Software 2D drawing: colors, an anti-aliased canvas and fonts.

Everything is drawn by Pastel itself into a 32-bit pixel buffer, so it looks the same on every platform. A GPU backend (e.g. Skia) can later implement the same drawing calls.

uses Pastel.Graphics; · source: framework/src/pastel.graphics.pas

Contents: TRectI · TPastelFont · TBitmap32 · TCanvas32 · EPastelGraphics · RGB · RGBA · WithAlpha · Mix · TryParseColor · RectI · NextCodePoint · PrevCharStart · FitText · GetFont · SetFontFiles · PascalFonts

S cut to fit Width (pixels of Font), with '…'; one line (a line break ends it). Quick for long texts: only what can fit is measured, the cut found by halving.
