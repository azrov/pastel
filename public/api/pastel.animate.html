#Pastel.Animate

Animations: a property goes to a new value smoothly.

Animate(Panel, 'Height', 240);                         // 250 ms, slowing down at the end
Animate(Card, 'Left', 0, 400, eaOutBack);              // a little past, then back
AnimateColor(SaveButton, 'Color', $FF43A047, 300);
Animate(Bar, 'Position', 100, 1500, eaLinear, @Loaded);
StopAnimations(Panel);

Any published number property (Integer, Single, Double: Width, Height, Left, Top, Position, Value...) or color (TColor32). An animation of the same property replaces the one before (from where it is). A control that is freed takes its animations with it.

uses Pastel.Animate; · source: framework/src/pastel.animate.pas

Contents: TEasing · TAnimation · Animate · AnimateColor · StopAnimations · IsAnimating · Ease · StepAnimations

#Animate

Starts it; the property is set at once on every frame until DurationMs passed.
