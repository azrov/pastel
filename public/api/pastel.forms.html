#Pastel.Forms

Building forms from .pform data.

The code Pastel generates for each .pform file registers the form's source here. When a form is created, its controls are built from that source and properties and events are set through RTTI, like Delphi does with .dfm. Internal unit: used by Pastel itself and by the code it generates; it may change between versions.

uses Pastel.Forms; · source: framework/src/pastel.forms.pas

#TFrame

type TFrame = class(TColumn)

A part of forms with a .pform and code of its own, used on many forms: an address block, a customer card. Its .pform starts like a form's, with a type whose name ends in Frame: // Address.pform object AddressFrame: TAddressFrame object StreetEdit: TEdit end end and a form puts it where it wants it, as often as it wants: object Billing: TAddressFrame end object Shipping: TAddressFrame end Its controls are its own (Billing.StreetEdit, Shipping.StreetEdit); its events go to its own methods. "pastel new frame Address" makes one.

#ViewForScreen

function ViewForScreen(Form: TForm; AClass: TScreenClass): string

The view a form uses on a kind of screen ('' for none): its own, or tablet for a TV without one.

#ApplyFormView

procedure ApplyFormView(Form: TForm; AClass: TScreenClass)

Applies the form's view for the kind of screen: the values the view sets replace the form's (and come back when another kind of screen has no view).

What the user changed in the controls (typed text, checked boxes, chosen items, the page of tabs), by control name; hot reload puts it back.

#FormStateText

The form's state as one text, for a phone that stops the app in the background: what is in its controls, and its SaveState (after OnSaveState).

#BuildForm

procedure BuildForm(Form: TForm; Root: TPFormNode)

Creates the controls described by Root on Form, then binds fields. Raises EPFormError on problems (unknown type, property or event).

#RefreshFrameSources

function RefreshFrameSources(Fetch: TFormFetcher = nil): Boolean

Hot reload of frames: reads the .pform files of the frames again (Fetch reads a file on a phone); True when one changed (their forms are then built again).
