#Pastel.Controls

More controls: check boxes, radio buttons, switches, lists, drop-downs, pictures, scrolling areas, tabs, progress bars, sliders, spinners, splitters, tool bars and status bars. They are registered for .pform files like the basic ones.

uses Pastel.Controls; · source: framework/src/pastel.controls.pas

Contents: TCheckBox · TRadioButton · TSwitch · TListBox · TDrawer · TBottomSheet · TComboBox · TImage · TScrollBox · TTabSheet · TTabPosition · TTabControl · TProgressBar · TSlider · TSpinner · TSplitter · TToolBar · TStatusBar · FindAppFile

#Types

#TRadioButton

type TRadioButton = class(TCheckBox)

One choice of several: checking it unchecks the radio buttons next to it (with the same parent).

type TSwitch = class(TCheckBox)

An on/off switch with an optional text after it.

#TDrawer

type TDrawer = class(TPopup)

A drop-down list. A panel that slides over the window from its left (or right) side: the menu of a phone app (the "hamburger" menu). It holds controls like a column; it is not on the form until Open. #TSplitter

type TSplitter = class(TControl)

A bar between two controls of a TRow (or a TColumn) that the user drags to share the room between them. It changes the Width (in a column: the Height) of the control before it; give that one a Width and the one after it Grow = 1.
class function DesktopOnly: Boolean
constructor Create(AOwner: TComponent)
function Target: TControl The control it resizes: the visible one before it; nil when there is none.
procedure MoveTo(Size: Integer) Gives the target this size (clamped between MinSize and the room there is).
property MinSize: Integer The smallest size of the controls on both sides.
property OnMoved: TNotifyEvent The user let go of it at a new place.
