#Pastel.Device

The phone's features: share, open, vibrate, notify, pick a file, take a photo, find the place; and the permissions they need.

ShareText('Your appointment: Monday 10:00');          // Android's share menu
ShareFile(InvoicePdf);                                // the PDF to WhatsApp, mail...
OpenUrl('https://maps.google.com/?q=Istanbul');       // the browser (a file: the app for it)
Vibrate;                                              // a short buzz
Notify('Sync', '12 appointments came in');            // in the notification bar
Photo := TakePhoto;                                   // '' when cancelled
FileName := PickFile('application/pdf');              // '' when cancelled
if GetLocation(Place) then
  Label1.Text := Format('%.5f, %.5f', [Place.Latitude, Place.Longitude]);

On Android these use the phone's own apps and services through Pastel's activity; the calls that wait (TakePhoto, PickFile, GetLocation, RequestPermission) keep the app's window alive while they wait. On a computer: OpenUrl opens the browser or the file's app, PickFile shows the open dialog, Notify uses the desktop's notifications on Linux; the others answer False / '' (no camera, no place).

The calls that wait have a second form that does not: it returns at once and calls a method of yours with the answer — the way for phones: TakePhoto(@PhotoTaken); ... procedure THomeForm.PhotoTaken(Sender: TObject; Ok: Boolean; const FileName: string); begin if Ok then Image1.LoadFromFile(FileName); end;

Permissions: GetLocation asks for the location itself; an app that uses it lists it in pastel.toml: [package.android] permissions = ["location"].

#TPermissionState

type TPermissionState = (psGranted, psNotAsked, psDenied, psBlocked)

psNotAsked: never asked (asking shows the phone's question); psDenied: refused once (explain why the app needs it, then ask again); psBlocked: refused for good (only the app's page in the settings gives it: OpenAppSettings)

  • psGranted psNotAsked: never asked (asking shows the phone's question); psDenied: refused once (explain why the app needs it, then ask again); psBlocked: refused for good (only the app's page in the settings gives it: OpenAppSettings)
  • psNotAsked psNotAsked: never asked (asking shows the phone's question); psDenied: refused once (explain why the app needs it, then ask again); psBlocked: refused for good (only the app's page in the settings gives it: OpenAppSettings)
  • psDenied psNotAsked: never asked (asking shows the phone's question); psDenied: refused once (explain why the app needs it, then ask again); psBlocked: refused for good (only the app's page in the settings gives it: OpenAppSettings)
  • psBlocked psNotAsked: never asked (asking shows the phone's question); psDenied: refused once (explain why the app needs it, then ask again); psBlocked: refused for good (only the app's page in the settings gives it: OpenAppSettings)

#TPlace

type TPlace = record
Latitude: Double

#TSharedContent

type TSharedContent = record

What another app shared with this one (Android's share menu).
Text: string
Subject: string
MimeType: string 'text/plain', 'image/jpeg', 'image/*'...
Files: TStringArray the files, copied into the app's cache

#TShareReceiver

type TShareReceiver = class(TComponent)

The app in other apps' share menu: put it on the main form (it is not drawn); OnShareReceived gets what was shared — also what opened the app. pastel.toml lists the kinds: [package.android] receive_shares = ["text/plain", "image/*"].
property OnShareReceived: TShareReceivedEvent

#TContact

type TContact = record

A person of the phone's contacts.
Name: string
Phones: TStringArray
Emails: TStringArray

#TCalendarEvent

type TCalendarEvent = record

An event of the phone's calendar; local times (an all-day event: its days, Finish the day after).
Title: string
Place: string
Notes: string
Start: TDateTime
Finish: TDateTime
AllDay: Boolean

#TAppShortcut

type TAppShortcut = record

A shortcut of the app's icon (a long press on it): its Id comes back in TLinkReceiver.OnShortcut; Icon is a built-in icon's name ('add', 'calendar'...).
Id: string
Title: string
Icon: string

#TLinkReceiver

type TLinkReceiver = class(TComponent)

Links that open the app and the shortcuts of its icon: put it on the main form (it is not drawn). OnLink gets the address - also the one that started the app - for the links in pastel.toml: [package] links = ["shop://", "https://shop.example.com/app"]. OnShortcut gets the Id of a shortcut (SetAppShortcuts). On computers a link of the app's own scheme (shop://) starts it with the address (the .deb and the Windows installer register it).
property OnLink: TLinkEvent
property OnShortcut: TShortcutEvent

#TAuthKind

type TAuthKind = (akNone, akDeviceLock, akBiometric)

What the device can check the user with: nothing set up, the screen lock (PIN, pattern, password), a fingerprint or the face.

  • akNone What the device can check the user with: nothing set up, the screen lock (PIN, pattern, password), a fingerprint or the face.
  • akDeviceLock What the device can check the user with: nothing set up, the screen lock (PIN, pattern, password), a fingerprint or the face.
  • akBiometric What the device can check the user with: nothing set up, the screen lock (PIN, pattern, password), a fingerprint or the face.

#Authenticate

procedure Authenticate(const Reason: string; OnDone: TAuthDoneEvent; AllowPin: Boolean = True; const Subtitle: string = '')

"Is it you?": the fingerprint, the face or (AllowPin) the phone's PIN, pattern or password, with Reason shown - before a payment, to open the app's secrets. Android 9 and newer the system's dialog; older ones the lock screen's check. Computers: not there (OnDone with False).

#ScanBarcode

procedure ScanBarcode(OnDone: TScanDoneEvent)

A QR code or barcode read with the camera: Google's code scanner (its own screen, no camera permission) with [package.android] libraries = ["com.google.android.gms:play-services-code-scanner:16.1.0"]. Computers: not there.

#KeepScreenOn

procedure KeepScreenOn(Enable: Boolean)

The screen stays on while the app is open (a recipe, a map, a kiosk); False: it goes dark by itself again. Phones.

#SaveToGallery

function SaveToGallery(const FileName: string; const Folder: string = ''): Boolean

A picture (a photo of TakePhoto, a chart saved as PNG) into the phone's gallery, in Pictures/Folder (default: the app's name); False and LastDeviceError when not. Computers: copied into the user's Pictures folder.

#SetAppShortcuts

function SetAppShortcuts(const Shortcuts: array of TAppShortcut): Boolean

The shortcuts shown by a long press on the app's icon (Android 7.1 and newer; up to 4 are shown); [] removes them. They stay after the app ends: set them at every start (in the user's language). False and LastDeviceError where not.

#PickContact

procedure PickContact(OnDone: TContactDoneEvent; Email: Boolean = False)

The phone's contact list to choose one from (no permission needed): its name and the number (or with Email the e-mail) chosen, in Phones[0] (Emails[0]).

#ReadContacts

function ReadContacts(out Contacts: TContacts; const Search: string = ''): Boolean

All contacts with their numbers and e-mails, by name; only those with Search in their name, number or e-mail. Needs the permission: [package.android] permissions = ["contacts"] and RequestPermission(dpContacts).

#AddContact

function AddContact(const Name: string; const Phone: string = ''; const Email: string = ''): Boolean

The contacts app with a new contact filled in: the user saves it (no permission).

#AddToCalendar

function AddToCalendar(const Title: string; Start: TDateTime; Finish: TDateTime; const Place: string = ''; const Notes: string = ''; AllDay: Boolean = False): Boolean

A new event in the calendar app, filled in: the user saves it (no permission). Computers: an .ics file, opened by the calendar program (Thunderbird, Outlook...).

#ReadCalendar

function ReadCalendar(out Events: TCalendarEvents; From: TDateTime; Till: TDateTime): Boolean

The events of the phone's calendars from From till Till. Needs the permission: [package.android] permissions = ["calendar"] and RequestPermission(dpCalendar).

#EnterPictureInPicture

function EnterPictureInPicture(AspectW: Integer = 16; AspectH: Integer = 9): Boolean

The app's window small, over other apps, with its video playing (Android 8 and newer, [package.android] picture_in_picture = true). Show only the video meanwhile: the form gets the small size (OnResize), InPictureInPicture says why. False and LastDeviceError where not.

procedure AutoPictureInPicture(Enable: Boolean; AspectW: Integer = 16; AspectH: Integer = 9)
